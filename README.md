# Mystery Book

This is a minimal, glassmorphic archive for unsolved mysteries, unexplained events, and paranormal case files — browsable by country, sortable by popularity or date. Built with Next.js (App Router), TypeScript, Tailwind CSS, and shadcn/ui. Frontend-only for now; backend coming next.

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui + Radix primitives
- Lucide icons

## Features

- Landing page with country-based case discovery
- Glassmorphic UI — navbar, search panel, category cards, featured case
- Discover page with country heading, sort bar (Most Popular / Date), and case grid
- Fully responsive, minimal animation

## Getting started

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`.
